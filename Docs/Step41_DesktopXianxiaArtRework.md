# 第 41 步：桌面修仙主题统一重制

## 最新方向（2026-09-06）

参考《桌面副本物语：放置好时光》的桌面横条、透明留白、局部植被和挂机呈现，制作原创修仙主题游戏。不是只给原有写实人物换一个像素按钮。

- 重做所有战斗演员的外观与 Idle / Move / Attack / Hurt / Death，包括玩家、普通怪、Boss、灵宠。
- 保留现有独立飞升动画；不因此扩展新的灵界、仙界玩法。
- 场景不恢复整张不透明天空背景，改为按地图切换少量树木、草丛、岩石等局部装饰。
- 功能页继续图形化，详细数值保留必要文字，不将全部信息变成无法识别的图标。
- 旧素材和导入配置保留，新版先进入独立 `DesktopPixelV2` 目录，逐批验收后接替运行引用。

## 发现的问题

1. 现有玩家为 8/8/8/6/8 帧，约 8–12 FPS 的半写实独立姿态。帧数、尺寸、Pivot 自动化通过，不等于动作流畅；原第 38 步“完成（当前版本）”不适用于这次重制要求。
2. 玩家受击会清除攻击动画计时器并重播受击；密集受击可能导致动作频繁中断。实际攻击结算与动画时长也需要统一验证。
3. 怪物与灵宠目前主要复用移动动画，缺少独立站立等待表现；可造成停在原地仍踏步。缺 Idle 资产时应明确回退，不伪称已完成新版待机。
4. 当前透明桌面采用色键合成。现有玩家导入配置使用 Translucent，半透明边缘会与保留色混合，出现泛色。新版演员应使用清晰透明边缘及 Masked 材质，不能仅修改背景掩盖。
5. 各演员比例、帧间脚线、武器与尾巴范围须统一检查，不能按每帧单独居中缩放，否则动画会抖动。

## 分批交付

1. 透明模式、缩放与基础 UI 的第 40 步收尾。
2. 玩家统一锚点样稿与青云山局部植被；建立动作质量检查与导入约定。
3. 玩家五套基础动作及状态切换实机验证。
4. 青云山妖狐、灵犬/妖狼、当前灵宠动作重制。
5. 现有 Boss 和其他已开放地图演员逐套替换；每批记录尚未覆盖项。
6. 其余人界地图装饰与功能页美术统一验收。

## 地图装饰主题

| 地图 | 装饰主题 |
|---|---|
| 青云山 | 松树、青竹、灵草、青灰山石 |
| 妖狼谷 | 冷色针叶木、枯枝、山谷碎石 |
| 万妖林 | 宽叶古木、藤蔓、蕨草 |
| 黑风洞 | 岩柱、洞口枯草、少量冷光矿石 |
| 上古遗迹 | 残柱、苔藓、石阶碎片 |
| 幽冥谷 | 枯木、紫灰灌丛、少量幽光草 |

装饰不参与碰撞，不遮挡角色攻击区和 HUD；中部及上方保留充足桌面可视区域。分辨率变化或切地图时重排，不在每帧重新随机生成。

## 质量门槛

- 外观一致、清晰像素轮廓；先确认角色锚点再生产动作，不混用写实和像素批次。
- 同一动作使用相同画布、比例、朝向、脚底基线；移动走步有完整左右脚周期。
- 攻击包含预备、发力、接触、收势，伤害点与接触帧对齐；受击不能在每次小伤害时无限重启。
- 待机与移动循环首尾连贯；死亡只播放一次并保持末帧；复活后清理旧状态。
- 不通过重复帧、单纯提速或将一个静态图做位移来宣称“全部动画重制”。
- 生成样稿、透明检查、运行导入、实机播放分别记录。未接入的样稿不计作完成资产。
