# 46：R06 共用物品图标与辅助标识

实施：2026-09-30；最终验证：2026-10-01。依据 `D:\ARPG\仙途项目现状与改进清单_2026-09-22.md` 的 R06。本批完成物品图标与辅助标识的源码修复；不将透明桌面全部视觉验收、法宝新插画或演员美术重制计入完成范围。

## 本批范围

- 背包与装备栏使用现有 `ImmortalCraftingArt`、`ImmortalAlchemyArt` 共用映射：九种装备各用独立的 3×3 图集区域；九种材料、五种丹药使用对应炼器/材料/炼丹图集。不再用衣服代替护腕、腰带，或用同一饰品代替两枚戒指。
- 将必要的物品回退字形保留在控件树中，图集正常时隐藏字形；护腕、腰带、左右戒指使用独立的小角标。数量/等级、品质框、锁定、选中和空槽每次刷新先重置，避免复用控件时残留。
- 背包详情直接复用同一物品格控件，避免出现第二套图标映射。预览不响应点击；原有属性、比较和操作按钮保留。
- 百宝阁列表、购买详情、出售详情复用上述图集；缺少图集时使用明确的类别符号，不留空白，不叠加符号与插画。
- 材料实体掉落直接用 MaterialId 查共用图集，不依赖显示名字反查；保留名称与数量，缺图时显示已有字形。
- 任务物品保留三种明确字形；法宝保留目录字形、品质、锁定及等级星级。法宝新插画属于 R10，本批不声称已完成，也不提交其在制文件。

- 运行夹具逐类选择物品，核对背包格与详情、商店当前行与详情、炼丹页、材料实体掉落；另外清空商店实例的软引用以验证缺图回退。选择商品后重新取得重建的当前行，不检查已经移除的旧控件。
