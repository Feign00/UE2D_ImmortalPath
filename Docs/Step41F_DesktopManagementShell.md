# 第 41F 部分：透明桌面统一管理框架

日期：2026-09-08。状态：本批完成；不是全部功能页美术重制完成。

## 本批范围

- 管理页和独立飞升页在同一个原生窗口内向上展开；收起管理页恢复用户设置的战斗横条高度，不改写用户的高度偏好。
- 管理内容为居中的等比缩放面板，左右与上方保留透明留白，底部预留原战斗高度。窄屏自动缩放；无法扩展的紧凑 PIE 视口优先保证菜单可用。
- 在投影数据层补偿新增窗口高度，使世界演员保持原来的桌面位置；世界坐标、摄像机组件、怪物生成和战斗逻辑不移动。屏幕位置查询使用同一投影，避免头顶血条和掉落提示错位。
- 洞府集中修炼、宗门、炼丹、炼器、洞府营造和灵田；坊市提供百宝阁；角色页集中装备、法宝、功法、灵根和灵宠；历练台保留地图、任务、妖王和秘境。新增主导航飞升入口，继续调用原独立飞升页。
- 管理背景由全窗口铺图改为局部面板内显示。共用深青底、金色细边、图标及短标签；详细功能页不再叠加主页场景图。现有图标和旧场景资源保留，尚未生成新建筑或逐页正式美术。
- 普通切页不暂停刷怪；死亡恢复仍由角色层强制重定向至修炼，飞升入口不能绕过门禁。
- 掉落提示移到管理面板下方留白，不覆盖详细页底部操作。

## 验证记录

1. UE 5.7.4 Development Editor 与 Game 最终构建通过。完整 `ImmortalPath.` 测试在 `Saved/TestReports/Panel41FVerified/index.json` 中为 50 成功、0 警告成功、0 失败、0 未运行。
2. 新增共享布局测试：覆盖 1280×720、1707×1018、2560×1400 工作区和三档高度的边距、底部战斗预留、收起恢复及透视/正交投影数学行为。此项不是这些分辨率全部经过原生点击验证的声明。
3. `-ImmortalTestDesktopPanels` 仅允许 `Saved/Automation/DesktopPanels` 下的隔离 UserDir。最终 `Release41F` 独立运行 12 项检查全部通过、`failures=0`、退出码 0；覆盖八个功能页、飞升独立页、展开和收起。正常页面切换期间自动攻击计时器保持运行且世界未暂停。
4. 实际 2560×320 战斗条展开为 2560×680；玩家投影从 `(724.29,160)` 变为 `(724.29,520)`。原生窗口向上展开 360 像素，因此演员在桌面上的位置保持一致。
5. 首轮集成发现只平移投影会触发 MaintainYFOV 缩放，角色横向位置从 724.29 变为 99.11；修复为先重建原战斗条投影，再嵌入高窗口。首轮布局测试还发现浮点边距略低于 24，生产布局增加明确的最小边距约束，未放宽断言。
6. 桌面实际点击已覆盖洞府、修炼、坊市、百宝阁、飞升及收起路径。原生透明检查的固定 `(50,50)` 前景采样点在展开状态处于透明留白，曾产生误报；改为寻找稳定的非色键实色区域，不改变生产透明合成逻辑。
7. 额外回归 41E 战斗检查时，开局攻击的残留单次动画使移动/待机两项失败；测试隔离世界后明确清理该视觉状态，再开始移动测试。未改变运行时移动或攻击规则。死亡、复活和强制修炼门禁在该轮已通过。

8. 修正后的 `PixelIntegration/Panel41FFinal` 共 19 项战斗检查全部通过、`failures=0`、退出码 0，包含死亡强制修炼和复活不解除历练锁定。
9. `DesktopPanels/NativeFinal41F` 使用 DX11 实际桌面验证：紧凑与展开状态的 `sourceKey`、`nativeKey`、`desktopVisible`、`foregroundVisible` 均为 true。桌面检查技能实际点击打开洞府与修炼，并确认通知位于面板外的下方留白、操作按钮可见；收起恢复底部横条，演员继续战斗。
10. 最终在菜单展开状态下以 Alt+F4 关闭隔离测试游戏，退出码 0，日志记录正常引擎关闭，窗口列表确认测试窗口销毁。未进行逐帧退出录像分析。

编译过程中曾出现 UHT/UBT `System.AccessViolationException`、MSVC C1060 和多个未改动文件中的 C1001。系统当时仍有约 21 GB 可用物理内存，不把这些异常直接解释为项目内存不足，也不据此断定硬件故障。后续将编译命令进程临时固定到逻辑处理器 16（亲和掩码 65536）串行执行；不修改系统设置或用户应用，不关闭业务测试。

新增投影代码曾因局部变量 `Size` 遮蔽基类成员触发 C4458，已改名 `ViewportSize` 后重新构建通过。
