# 第 41N 部分：炼丹大面板与丹药、材料图集

日期：2026-09-12。本批炼丹大面板、丹药/材料图集和相应交互验收完成。

## 范围

- 炼丹页从 1600×270 改为 1600×600，三栏分别为丹方、炉台与材料消耗、丹药背包/服用。所有操作仍在同一管理容器内，普通菜单不暂停历练。
- 原创五丹药及丹炉图集、六材料图集，由内置 image_gen 生成。原始 1536×1024 RGBA 保留，不裁切或去底；按 ID 映射 3×2 单元。材料图集的灵石单元预留，暂未替换全局背包/掉落图。
- 丹方为 264×94 大行，配 64 像素图标；丹药格 92×92，五列排列，品质以“普/极”、颜色、悬停文字与所选详情区分。
- 消耗列表显示材料图片、实际持有/消耗及充足/不足；缺失或扩展 ID 不冒用别种图片。原丹药汉字仅保留为缺失图片回退。
- 原有成功率、极品概率、材料扣除、丹药效果、境界解锁与死亡恢复规则不改。不以新版 UI 代表新的玩法。
