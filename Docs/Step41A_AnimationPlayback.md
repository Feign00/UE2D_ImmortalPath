# 第 41A 部分：动画播放状态修复

## 范围

这是全演员美术重制前的播放逻辑修复，不是五套新动画交付。

- 怪物（含继承同一基类的 Boss）和灵宠根据实际横向速度选择待机/移动，低于等于 5 cm/s 的微小抖动不触发跑步。
- 增加可选 `IdleFlipbook`：怪物在蓝图默认值指定，宠物在定义表指定。现有数据没有 Idle 时，停下保持 Move 第一帧；不会将 Move 循环伪称为呼吸待机。
- 重复更新同一循环不重置播放进度。恢复移动后能够从静止姿态继续播放。
- 攻击、受击和死亡仍由演员原有状态控制，移动更新不能覆盖这些一次性动作。
- 玩家、怪物连续受击时保留同一 Hurt 的进度；原有伤害扣除、攻击打断和受击恢复计时规则不变。连击仍可能延长硬直并保持末帧，这次不擅自改变战斗平衡。
- 保留原攻击前摇、攻速、掉落、修为与飞升逻辑。后续新攻击素材制作时再校对接触帧，不声称本批已完成全演员伤害帧同步。
