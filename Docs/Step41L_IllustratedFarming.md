# 第 41L 部分：灵田插画与大面板

日期：2026-09-10。本批灵田展示、原生交互验证完成；不代表整个人界美术改版完成。

## 实现

- 灵田由旧 1600×270 横条重排为 1600×600，接入现有桌面管理外框。左侧三种作物图文按钮、成长/消耗说明和批量播种；右侧六块田采用 3×2 卡片、独立进度条及操作按钮。
- 内置 image_gen 生成原创修仙作物图集：空田、幼苗、灵草、仙果、灵木、锁定田。不是从参考游戏提取素材。源 PNG、完整提示词、透明通道说明见 [素材记录](../ArtSource/MortalRealm/DesktopPixelV2/Farming/README.md)。
- 原始 RGBA 不抠图、不逐格拉伸，通过 UMG UV 读取 1536×1024 的六格图集。透明边缘用于管理页，不用于桌面色键演员。
- 图集使用可反射软引用，导入为无损 RGBA、无 mip、常驻 UI 纹理。缺失图集时田块保留文字回退，不显示白色矩形。
- 幼苗有独立图片；生长中、将成熟、成熟共享对应作物插画，由状态文字、进度和金色成熟卡片区分。这不是逐阶段生长动画。
- 不改变播种消耗、产出、离线成长、等级门槛或存档格式；普通菜单切换继续战斗，击杀不增加修为，原有飞升动画保留。

## 原生鼠标及视觉验收

使用当前桌面 2560 像素宽、150% 系统缩放、DX11 原生透明窗口，两个独立 UserDir：`Saved/Automation/DesktopPanels/Native41L` 和 `Native41LMature`。没有使用编辑器截图代替原生合成检查，也没有提交含桌面背景的截图。

1. 等级 1：两块空田与四块锁定田显示正确，图集无黑底/棋盘底；单块播种切为幼苗，五分钟倒计时与进度正常更新。
2. 三个作物按钮逐个点击：仙果/灵木显示各自图片、消耗与 Lv5/Lv9 要求，并禁用不满足等级的播种。
3. 切回灵草，批量播种仅播种剩余 1 块空田；已占用田与锁定田不受影响。页内关闭返回洞府，再点击灵田建筑成功重入，计时继续。
4. 成熟 fixture 用现有开发参数建立等级 20 和六块成熟仙果（仅隔离进度），六张金色成熟卡片和产量可读。真实点击单块收获，仙果库存 0→6，田块回到空田；一键收获其余五块得到 33，库存 6→39，六块全部为空，收获按钮禁用。
5. 误点上栏飞升入口时打开的是独立飞升条件页，未执行飞升；关闭按现有导航返回修炼页。之后点击右上收起，恢复紧凑透明战斗条。全过程底部演员继续攻击，灵石数量持续变化。
6. 两轮均通过 Alt+F4 正常退出，进程返回 0。原生观察中未出现新的整块黑背景；旧怪物、宠物和法宝素材的紫红边缘仍在，不把它们算作已修复。
