# 42：R01 存档防覆盖与恢复入口

日期：2026-09-23。依据 `D:\ARPG\仙途项目现状与改进清单_2026-09-22.md` 的 R01，顺带封住同一读取路径上的 R03（较新版本存档继续游玩却不能保存）。本阶段不改动战斗、掉落、修炼、美术或正式存档。

## 实现范围

- 主存档分为不存在、可读取、无法读取、较新版本等状态；主档缺失但备份仍存在时不自动建档。仅确实没有主档和备份的槽位开始新进度。
- 读取时复核完整序列化数据流；短截断、保留文件头但截断尾部、错误 SaveGame 类型均按无法读取处理。读取失败不能走新档初始化与自动保存。
- 每次覆盖可读取主档前，先保存上一份有效数据到 `_Backup`；主档损坏、主档缺失但备份仍存在、备份为较新版本或文件存在状态未知时拒绝写入。主档有效而旧备份损坏时则用有效主档重建备份，取舍见下文。
- 遇到无法读取或不兼容的主档时，玩家与刷怪器停止正常进度，显示常驻恢复界面。有可用备份时提供明确的“恢复上一份备份”操作；恢复后重新打开当前关卡。没有可用备份时只允许安全退出，并提示保留文件。
- 恢复不会自动覆盖一个仍可读取的主档。较新版本的主档或备份由旧程序保持只读保护，不允许用旧备份替换。主档可读但备份来自较新版本时也在进入普通游戏前拦截，避免进入后每次保存失败。
- 恢复界面五种状态的标题、说明、恢复入口可见性由独立 UI 自动化测试覆盖。
