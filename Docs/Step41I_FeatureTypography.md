# 第 41I 部分：功能页字号、空间与滚动样式

日期：2026-09-08。

## 范围

- 宗门、灵田的 1600×300 旧内容画布重排为 1600×270，与管理内容区高度相符，避免在嵌入时额外缩小。保持原生窗口尺寸与底部战斗摄像机不变。
- 宗门选择、每日任务、贡献宝库保留三个分区；灵田保留作物区、六个田块和批量操作。正文由原来的 10–13pt 提升到至少 14pt，核心说明 16pt。通过重新分配空间与独立滚动保留完整说明。
- 作物按钮只显示名称；时间、基础产量、成本与等级要求仍在所选作物详情中，原按钮信息另保留为悬停提示。
- 宗门选择按钮改为单行名称，状态由选中颜色与完整悬停提示说明；任务描述、进度、奖励合并到一行，避免需要滚动才能看到进度。宝库先显示贡献消耗与限购规则，再显示说明；领取/兑换按钮使用短操作词，不重复塞入成本数字。
- 炼丹描述/药效提升至 16pt；炼器装备属性/词条提升至 16pt，强化/洗炼成本提升至 15pt。
- 共用详情滚动区与炼丹/炼器列表采用细玉绿色滑块、金色悬停/拖动状态，移除遮住末行的黑色渐变阴影；不启用越界弹性滚动。没有生成或替换美术图片。
