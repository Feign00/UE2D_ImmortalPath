## 本项目改造方案（待分批实现）

保留已有同一游戏窗口内的管理界面和底部战斗条，不新增操作系统窗口。页面外透明，内容区保持可读的实体底板，不把文字直接铺在桌面上。

| 页面 | 结构与操作方向 |
|---|---|
| 角色 / 储物戒（下一批优先） | 角色与装备槽、背包图标格、固定所选装备详情；筛选与整理集中；对比当前装备，显示提升和损失；沿用已有穿戴、锁定等能力，不冒充新功能 |
| 炼丹 / 炼器 | 配方图标列表、材料图标与已有/需要数量、产物预览、固定主操作按钮；长说明进入详情，不挤进按钮 |
| 修炼 / 宗门 / 灵田 | 保留洞府入口场景；进度、可领取奖励和解锁条件用卡片表达，必要数值和短文字仍保留 |
| 百宝阁 | 商品格与选中详情、价格与购买数量分区；使用独立坊市场景和同一套边框/按钮状态 |
| 历练 / 飞升 | 历练主要展示关卡与进入条件；飞升继续独立界面与原飞升动画，不与普通菜单混为一体 |

统一深墨绿底、浅米色正文、玉色选择态、金色主操作和品质色；最终采用原创修仙边框与图标，不复制参考游戏的卷轴、角色、装备图片、Logo 或文案。当前建筑插画与像素演员还需要后续统一美术验收。

## 开发边界与验收

- 优先改已有功能的表达与操作，不因为参考游戏有多职业、小队或抽取系统就增加这些玩法。
- 战斗不提供修为，修炼独立；死亡历练锁定与修炼恢复规则不变，普通切页不能暂停战斗。
- 每批覆盖空背包、满列表、长装备名称、多词条、资源不足、可操作/不可操作状态；实际鼠标选择、滚动、返回与关闭均需验证。
- 当前 41I 仅完成四个功能页的字号与空间整理。本方案没有被标记为已实现；按批编译、测试、提交与推送。
