## 失败与限制

1. 第一版预览检查误用了 Paper2D 的 protected API，编译失败；已改用公开时间取帧 API，随后 Editor 编译和完整测试通过。
2. 本机 PowerShell/.NET 两次 AccessViolation，以及一次 MSVC 链接器 LNK1000 内部错误。只调整构建进程环境、重试，没有修改引擎或删减测试。链接崩溃后的元数据成功不能作为完整链接证据，因此删除本批生成的游戏 EXE 并重新链接，确认最终 Link 和 WriteMetadata 都成功。
3. 原生桌面测试中 `sourceKey=true nativeKey=true desktopVisible=true foregroundVisible=false`；普通游戏、不带新版预览参数也复现。不能只看启动器退出码 0 宣称该测试通过。
4. 首次使用 computer-use 技能查看目标窗口时返回锁屏画面，按技能要求立即停止界面操作，没有尝试解锁或操作身份验证。该次前景采样失败记录保留，后续用户继续后已完成解锁环境复测（见下节），未通过降低测试条件把失败改为成功。
5. 本批仅通过预览接入：正式攻击伤害同步、密集受击、死亡转修炼、复活清理和完整五动作切换仍须下一阶段验证；怪物、宠物、Boss 和地图植被未完成重制。
