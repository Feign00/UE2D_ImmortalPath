# 第 40 步：透明桌面横条与图形化界面

## 本轮实现

- Windows 独立运行时采用无边框桌面底部横条，位置以当前显示器工作区为准，避开任务栏。
- 新增可保存的透明背景开关。透明的是场景背景，不是整个人物和界面；保留精灵、战斗、碰撞、掉落和存档逻辑。
- 背景使用保留色 `RGB(255,0,255)` 与 Windows 分层窗口合成。暗色人物描边不会像黑色色键那样被挖空。透明模式关闭后恢复原地图背景。
- 透明模式隐藏地图背景的渲染，不隐藏其碰撞；底部另绘制一条像素草地/石台。
- 战斗 HUD 改为血条加五个图标快捷入口：储物戒、修炼、百宝阁、仙府、设置。悬停显示名称。
- 原生绘制 20 个原创像素图标；管理场景、导航、背包材料与商品行采用图形标识和统一金玉色按钮。长说明仍保留必要文字，避免只剩难以辨认的图标。
- 七个已横向重排的功能页使用统一按钮风格，取消被压扁拉伸的旧背景框。
- 使用原生色键逐像素命中：透明像素穿透，实际绘制的按钮/页面接受鼠标。不再定时切换整窗 `WS_EX_TRANSPARENT`，避免鼠标点击竞态。
- 地面控件与鼠标检测随角色/世界销毁清理，不写入 RPG 存档。

## 使用与边界

1. 使用独立游戏运行（或后续打包版）查看透明效果。编辑器内 PIE 不修改编辑器宿主窗口。
2. 点击齿轮，在设置中切换透明背景；默认开启。
3. 游戏截图工具抓取的是合成前的游戏画面，可能显示洋红底；这不能单独判断桌面合成是否成功。
4. 当前为二值透明，不是完整的半透明桌面合成。半透明雾气、光晕边缘与 HDR/其他显卡环境仍需专项验收。
5. 图标来自 C++ 原生绘制。此前两次图片生成因网络失败，未接入任何声称已生成的 GPT 素材。
6. 本轮不新增灵界/仙界玩法，不替换飞升动画，不把击杀经验重新接回修为。
