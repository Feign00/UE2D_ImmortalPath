# 第 41E 部分：新版玩家正式战斗接入

日期：2026-09-07。状态：本批完成；不等于全演员或整体界面重制完成。

## 范围

- 现有 Player 蓝图默认使用 DesktopPixelV2 的 Idle / Move / Attack / Hurt / Death，五套均为 8 帧。原素材和独立飞升动画保留，不修改飞升资产。
- 新动作以反射软引用配置，完整校验后一起选用；缺失任一动作时整族退回原版，不混合两种人物外观。软引用为烘焙依赖提供可发现性，但本批没有进行打包/烘焙验证。
- 接触姿态为 Attack 第 4 帧（索引 3）。播放速率随既有攻击前摇适配，不改变伤害、攻击间隔、装备或成长数值。零前摇从接触帧开始并保留收势。
- 普通受伤立即扣血；正在挥剑时仅将视觉受击排队一次，攻击结束后播放。连续受击不重启动作，也不延长原结束时间。死亡立即抢占攻击和受击，取消未结算攻击。
- 死亡保持末帧；复活恢复新待机并清除旧状态，不绕过死亡后的强制修炼/历练关闭规则。战斗仍不提供修为。
