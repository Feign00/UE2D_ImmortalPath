# 第 41J 部分：大管理面板与储物戒三栏布局

日期：2026-09-09。按用户要求先同步源码；最终原生鼠标/视觉验收未完成，不作为最终美术验收版本。

## 本批范围

- 按 [参考方向](DesktopRaidUIReference.md) 重排既有储物戒页面：左侧当前角色待机静态展示与九件装备/一件法宝槽，中部七列物品格，右侧固定详情、同部位属性对比与单件操作。
- 根据用户最新要求，取消把所有功能压入低矮横条的限制。共用管理设计画布从 1707×320 扩大为 1707×680，内容区高度 610；原生窗口向上扩展，较小屏幕受工作区边界限制并等比缩放，关闭后恢复原战斗条高度。
- 储物戒重新排为 1600×600；84×84 物品格、两侧装备槽与底部饰品槽、较大的角色展示、纵向详情与属性比较。深墨绿分区与可缩放品质边框；沿用原素材，不生成新的位图或复制参考游戏素材。
- 洞府、角色、历练入口重新安排为两排大卡片，坊市为居中大建筑入口；炼丹、炼器等 900×600 功能页不再被 270 高度容器强制缩小。其余旧横向功能页仍需逐页进一步改造，不能把扩大容器等同于所有页面完成重排。
- 五类页签保留；整理与批量操作移至物品格底部，批量品质上限明确标作“批量”，不再误写成改变物品列表的筛选器。
- 新对比逐项显示非零属性增减，百分比属性采用百分点差。装备评分不是整个人物战力预测，明确提示尚未计入套装与流派联动。
- 长名称保留悬停全文；详情、对比和操作反馈独立滚动。切类别回到格子顶部，选择另一件装备回到详情顶部。刷新后立即预计算布局，避免同帧格子堆叠。
- 角色展示只读取现有待机动画族第一帧，不捕获世界、不改变角色动画或战斗摄像机。

## 保护规则

沿用自动拾取/自动比较装备逻辑，未新增手动穿戴或更改成长数值。锁定、出售/分解二次确认、背包变化取消待确认操作、任务物品保护继续使用原实现。普通管理页切换不暂停战斗，飞升与修炼规则不变。

测试入口 `-ImmortalTestInventoryPreview`（人工导航）和 `-ImmortalTestInventoryPanels`（自动流程）只在非 Shipping 且 UserDir 位于 `Saved/Automation/DesktopPanels` 内运行。入口填满测试背包并包含长名称、不同品质与锁定物品；正式存档不参与。
