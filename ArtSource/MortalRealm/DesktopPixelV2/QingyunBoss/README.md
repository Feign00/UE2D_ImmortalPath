## 生成与编辑约束（整理后的设计提示集，并非逐字历史调用记录）

共同要求：原创仙侠桌面 2D 游戏青云山守关九尾狐，白色毛发、冰蓝尾尖和金色纹饰；匹配项目既有像素演员的边线和视觉密度；左向四足侧视，清楚的九个物理尾尖，耳朵/颈毛不算尾巴。八个真实渐变动作，完整头、身体、四肢和尾巴，有透明边距，无背景、文字、地面、水印、残影或多角色。

- Idle：轻微呼吸、耳朵与尾扇摆动，身体比例/脚线稳定，末帧自然接回首帧。
- Move：四足交替支撑，前后腿抬起→前摆→落地→推蹬，尾扇跟随，小幅重心起伏；不重复站姿。
- Attack：准备→下压蓄势→蹲伏→开始开口→第 4 帧伸展咬击→合口跟随→收势→回到准备姿态。保证九尾和完整边距。
- Hurt：真实短暂冲击、抬腿/缩身、甩头后恢复；保留身份、四肢和九尾，不把动画变成另一个行走循环。
- Death：低头失衡→四肢弯曲→前躯倒下→躯干侧翻/卧倒→尾扇逐渐下沉→最终尸体；不得回到站立或循环。
- Idle 单帧编辑：只去掉第 3 帧多余尾巴，最终九尾；其他头、装饰、脚、姿势、画布位置保持。
- Attack 单帧编辑：只删去蓄势帧右侧倒数第二条多余尾巴，保留下侧尾巴和其他八条；其他头、身体、四肢、装饰及蓄势动作不变。

## 可复现整理

1. `*-regions.json`：显式人工原图矩形及连通域归属，alpha≥128 的全部原图像素必须分配一次，包括 1～2 像素边线孤岛；只搬移，不缩放/画新部件。
2. 两份 `*-normalization.json`：单帧工具只用一个真实 AI 姿势。工具导出实际为 1254×1254，按 **512/1254** 对整个画布做同轴最近邻归一化，不根据角色外框重新定大小；放进指定格，其余七格透明且不可选。
3. `*-assembly.json`：明确每帧来源，纯格拷贝；拒绝空帧、同一来源重复选择及精确像素重复。没有自动插帧。
4. `*-alignment.json`：人工躯干根/支撑脚锚点，统一目标 (256,336)，**所有动作整套缩放均为 0.7**；无分轴、逐帧外框缩放或人物拉伸。拒绝裁切和最终任何 QA 警告。

入口为 `ArtSource/Tools/prepare_authored_sprite_regions.mjs`、`prepare_reviewed_single_sprite.mjs`、`assemble_reviewed_sprite_atlas.mjs`、`align_sprite_atlas.mjs`、`audit_sprite_atlas.mjs`。先按配置整理原图与单帧、再拼帧、最后对齐；所有输出使用新的路径，拒绝覆盖原图/已有版本。具体 SHA 在配置与各套 `review.json`。

2026-10-14 独立从原图/配置重建 11 个中间 PNG 与 5 个最终 PNG，编码 PNG SHA 全部相同，51 个输入 PNG/JSON 前后不变。六组工具测试 60/60 通过。本地证据：`Saved/Automation/R07QingyunBoss/Rebuild20261014/rebuild-report.json`、`Tools/ToolsReview_20261014.md`；不上传个人存档、临时诊断图或日志。
